\chapter{Methods}

The probe-discovery method was implemented as a single, reproducible Python pipeline. Given a target
gene, the pipeline proceeds through the stages described below. It is built on Biopython (\acrshort{ncbi}
access and sequence handling), an external MAFFT executable (alignment), \texttt{primer3-py}
(thermodynamics), \texttt{seqfold} (secondary structure) and \texttt{pandas} (tabular output); the
three-dimensional structure prediction is run separately with Boltz-2 on a \acrfull{gpu}. Every design threshold is resolved
through a layered scheme that can be overridden per gene, per species and per organism type
(Section~\ref{sec:params}).

The description follows the order in which the stages run, and falls into three parts. The
sequence stages take a gene name and return a ranked list of candidate sequences, by retrieving
public records, aligning them, scoring their conservation and screening the resulting windows on
biophysical criteria. The best of those candidates are then predicted in three dimensions.
Finally, the predicted structures are placed on a graphene sheet and the resulting interface is
measured. Three shorter sections close the chapter: the scoring of an existing probe panel by the
same metrics, the diversity analysis that justifies the sampling depth, and the handling of
intermediate results.

\section{Sequence retrieval from NCBI}
\label{sec:retrieval}

For each target, sequences are retrieved from the \acrshort{ncbi} nucleotide database through the Entrez
interface. An \texttt{esearch} query returns up to a configurable number of identifiers (set to $100$ in
this work; justified in Section~\ref{sec:diversity}), which are then fetched with \texttt{efetch} in FASTA
format, in batches of $200$ identifiers, with short pauses between requests to respect the \acrshort{ncbi}
rate limit of three requests per second without an API key. Each target defines a primary query combining
the gene name, the organism and a sequence-length range; if it returns fewer than two records, the
pipeline falls back in turn to one or two broader alternative queries and, failing those, to a fixed RefSeq
accession. Records outside a coarse per-gene length range are discarded at this stage. For a gene with a
single usable record, a single-sequence mode is used.

\section{Length clustering}

Public records mix full-length genes with partial fragments and oversized entries, which together produce
gap-ridden alignments. The coarse length range of the retrieval query
(Section~\ref{sec:retrieval}) excludes only the grossest outliers; the records that survive it still
differ enough in length to degrade an alignment. An automatic length-clustering step therefore
retains only the dominant length cluster: the sequence length whose $\pm 25\%$ band contains the most
records is taken as the centre, and only records within that band are kept. Within the retrieved
range the selection is thus data-driven --- the band is placed by the distribution of the records
themselves, not by a bound set by hand for each gene --- so the method transfers to new genes without
further adjustment. It is applied only when at least four records are available, and the step is
skipped altogether if the dominant cluster would contain fewer than two records.

\section{Multiple sequence alignment}

The retained sequences are aligned with MAFFT in its automatic mode (\texttt{-{}-auto}). When only one
sequence is available the alignment step is bypassed and that sequence is used directly. The alignment of
each gene is stored, and the pipeline can restart from the stored alignments instead of querying
\acrshort{ncbi} again. Because the content of the database changes over time, this allows the downstream
parameters to be revised without changing the sequences on which the probes are based; all the results
reported in this dissertation derive from a single retrieval, processed in this way.

\section{Conservation scoring (PPI)}

With the sequences aligned, the first design criterion can be applied. A probe is useless if the
region it targets is present in only part of the strains of the pathogen, since the strains it
misses become false negatives; the alignment is what makes that measurable, column by column.

Conservation is scored per alignment column using the \acrshort{ppi}, adopted from the \emph{ViruScope}
tool \citep{viruscope}. For a column, the \acrshort{ppi} is the average identity over all pairs of
non-gap bases, computed from the base counts; pairs of ambiguous \acrshort{iupac} bases contribute a
partial weight (for example a purine code $R$ scores $0.5$ against $A$ or $G$, and $N$ scores $0.25$
against any base).
Columns in which fewer than $30\%$ of the sequences have a non-gap base are assigned zero, and only
columns with at least two non-gap bases are counted. Because the per-column \acrshort{ppi} is independent
of the window, it is pre-computed once per alignment, which is essential for hundreds of sequences. The
conservation of a candidate window is the mean of the \acrshort{ppi} of its valid columns. In contrast to
primer design, the identity of the terminal $3'$ nucleotides (scored separately as PPI3 in the original
tool) is deliberately excluded, because capture probes are not extended by a polymerase and so the fidelity
of their $3'$ end is irrelevant.

\section{Candidate generation}

Candidate probes are generated by sliding a window over the alignment. For each start position, taken every
$3$ columns, windows of every length from $18$ to $28$ nucleotides are formed. A window is discarded if
any of its columns has a gap fraction above the allowed maximum ($20\%$ by default), or if its mean
conservation is below the target's conservation threshold. The sequence of a surviving window is the
per-column consensus (the most frequent non-gap base).

\section{Thermodynamic screening}
\label{sec:thermo}

Conservation establishes that a region is shared across strains. It says nothing about whether an
oligonucleotide copied from that region would hybridise usefully, which depends on the stability
of the duplex it forms and on whether the strand instead pairs with itself. Those are
thermodynamic questions, and they are answered under the conditions in which the probe is meant
to work.

Each candidate is scored with \texttt{primer3-py} under the conditions of the reference buffer,
$1\times$ \acrfull{pbs}: $137$~mM NaCl, $2.7$~mM KCl, $10$~mM Na$_2$HPO$_4$ and $1.8$~mM KH$_2$PO$_4$
\citep{cshpbs2006}, that is, $157$~mM Na$^+$ and $4.5$~mM K$^+$, which \texttt{primer3} treats together
as a monovalent cation concentration of $161.5$~mM. No divalent cations or dNTPs are present, the
oligonucleotide concentration is $250$~nM and the temperature is $37\,^{\circ}$C. Four parameters are
computed for every candidate: (i) the melting temperature \acrshort{tm}, from the \acrfull{nn}
thermodynamic model \citep{santalucia2004}; (ii) the GC content, the fraction of G and C bases;
(iii) the hairpin free energy; and (iv) the homodimer, or self-dimer, free energy. The last two are
reported in kcal/mol and only when a structure is found. A candidate passes the
basic screen when its \acrshort{tm} and GC content fall within the resolved windows and its hairpin and
homodimer free energies are no more negative than their respective limits (Table~\ref{tab:params}).

The reference conditions are those of the intended application. Among the buffers used for DNA
detection with graphene transistors, $1\times$~PBS is the one whose osmolarity and ion concentration
approximate those of physiological body fluids \citep{purwidyantri2021}, and $37\,^{\circ}$C is the
physiological temperature; for the stability of the probe--target duplex it is also a more demanding
condition than room temperature. Computing every thermodynamic quantity under these conditions gives
each threshold a direct meaning. The \acrshort{tm} window is a margin over the hybridisation temperature
$T$: its default, $53$--$72\,^{\circ}$C, places the \acrshort{tm} between $16$ and $35\,^{\circ}$C above
$37\,^{\circ}$C, and for another assay temperature it can be derived as $[T+16,\,T+35]\,^{\circ}$C. The
lower bound keeps the duplex stable well above the hybridisation temperature; the upper bound excludes
probes so stable that hybridisation at that temperature would no longer discriminate imperfectly
matched targets \citep{wetmur1991}. The hairpin and homodimer limits are absolute free energies of
self-structure, so that, evaluated in the reference buffer, they refer to the stability of that structure
in the solution in which the probe is used. Because a higher ionic strength stabilises every
base-paired structure \citep{santalucia2004}, the same limits are more demanding in $1\times$~PBS than
at lower ionic strength, which is the intended consequence of evaluating the probes under their
conditions of use.

\section{Secondary structure and the No-fold score}

The single-strand secondary structure of each candidate that passed the basic screen is computed with
\texttt{seqfold}, which returns the \acrshort{mfe} at $37\,^{\circ}$C and the fraction of paired bases. A
candidate passes the secondary-structure screen when its \acrshort{mfe} is no more negative than
$-2.1$~kcal/mol. This value is the fifth percentile of the \acrshort{mfe} distribution of the candidates
that pass the basic screen in the reference buffer (Figure~\ref{fig:seqfold}). The \texttt{seqfold}
energies do not take the ionic strength as an input, but the population over which the percentile is
taken does depend on it, because the hairpin and homodimer filters that precede this screen are
evaluated in $1\times$~PBS; deriving the threshold from that population keeps it consistent with the
other criteria. Once derived, the value is fixed, so that the criterion remains reproducible across runs
rather than always removing a fixed fraction of the data.

In addition to this pass/fail screen, the three folding energies (hairpin, homodimer and \acrshort{mfe})
are combined into a continuous \emph{No-fold} score in the range $0$--$100$, following \emph{ViruScope}
\citep{viruscope}. Each energy is mapped through a logistic penalty,
\[
\text{No-fold} = \left(1 - \frac{1}{1+\exp(x)}\right)\times 100,
\qquad
x = \frac{\Delta G_{\text{cal}} - \Delta G_{0}/2}{s\,R\,T},
\]
with $\Delta G_{0}=-7000$~cal/mol, slope $s=1$, $R=1.987$~cal\,mol$^{-1}$K$^{-1}$ and $T=310$~K; the
per-probe No-fold score is the mean of the scores of the energies that are available. A high No-fold score
denotes a probe that is largely free of stable self-structure. This continuous score is used, together
with conservation, to rank the candidates rather than merely to filter them.

\section{Organism-aware parameters}
\label{sec:params}

Both screens just described were expressed in terms of the windows into which a candidate's
melting temperature and GC content must fall, without saying where those windows come from. This
section defines how they are resolved, which is what allows the method to transfer between
organisms.

Because the intended application spans pathogens with very different genomes, a single global set of
thresholds is inadequate: criteria appropriate for a balanced bacterial genome would unfairly reject an
AT-rich or a GC-rich target. All thresholds are therefore resolved from the most specific layer to the most
general,
\[
\text{gene} \;\rightarrow\; \text{species} \;\rightarrow\; \text{organism type}
\;\rightarrow\; \text{global default},
\]
where the first layer that defines a parameter wins. Five organism types are distinguished, differing
mainly in genome GC content and in variability (Table~\ref{tab:types}); species-level profiles then
fine-tune the values by the GC content of each genome (for example \emph{P.\ aeruginosa} at $\sim$67\% GC
\citep{stover2000}, \emph{A.\ fumigatus} at $\sim$50\% GC \citep{nierman2005} and the AT-rich
\emph{P.\ falciparum} at $\sim$19\% GC \citep{gardner2002}).

When the pipeline encounters an organism for which no profile exists and is run interactively, it prompts

\section{Quality-based selection}

Because three-dimensional prediction is comparatively expensive, only the best candidates per gene are
carried forward. Rather than ranking by melting temperature --- which the thermodynamic screen has already
bounded --- the surviving candidates are ranked by a \emph{quality} score that averages the two signals most
indicative of sequence quality:
\[
\text{quality} \;=\; \tfrac{1}{2}\left(\text{\acrshort{ppi}} + \tfrac{\text{No-fold}}{100}\right).
\]
The top-ranked candidates of each gene are exported for 3D structure prediction, and the same ranking is used to
export larger curated sets (for example the top $25$ per gene) together with their sequence-level features.

\section{Three-dimensional structure prediction}

Every criterion applied so far judges a probe by its sequence. None of them says what that
sequence looks like once folded, or how compact the resulting molecule is. Those properties matter
at a surface, where only what lies close to it can be sensed, so the next stage predicts the
structure itself.

The selected probes are written one per file in the native Boltz-2 input format and submitted to Boltz-2
\citep{wohlwend2024}, run on a \acrshort{gpu}, which predicts the three-dimensional structure of each single-stranded
sequence together with confidence estimates: an overall confidence, the \acrfull{plddt} and the \acrfull{pae}
matrix, in the style of AlphaFold~3 \citep{abramson2024}. As these confidence metrics are calibrated
primarily for proteins, the overall confidence and the \acrshort{plddt} are used here as relative,
independent indicators of the structural soundness of the short probes. The predictions are merged with the
sequence metadata to produce a final ranked shortlist combining sequence quality (conservation and No-fold)
with the 3D confidence.

Each selected probe was also predicted in its hybridised state, as a duplex with its full complementary
target of the same length (probe as chain A, target as chain B). This is the target format used in the
graphene-transistor studies that define the experimental context of this work, in which a
$25$-nucleotide probe was hybridised to its $25$-nucleotide complement \citep{campos2019,purwidyantri2021}.

\section{Assembly of probe--graphene models}
\label{sec:complex}

The structures predicted above are of the probe alone, free in solution. In a device the probe is
held against a graphene surface, and it is the geometry of that interface, not of the free
molecule, which determines how much of the probe's charge the transistor can register. Building
that interface requires a model of the surface as well as of the probe.

\subsection{Generation of the graphene sheet with GOPY}

The graphene component was built with \textbf{GOPY} \citep{muraru2020}, a free and open-source
Python tool for the automated construction of two-dimensional graphene-based molecular models.
Building such a lattice by hand is slow and error-prone, since every atom has to be positioned
individually; GOPY generates it programmatically, which makes a sheet of the size needed here
practical and reproducible. It writes the model directly in PDB format, so it can be read by
standard structural-biology software without conversion. The tool is distributed as a standalone
script under the GNU General Public License rather than through a package
index,\footnote{\url{https://github.com/Iourarum/GOPY}} and is run from the source obtained there,
which requires only Python~3 with \texttt{numpy} and \texttt{scipy}.

For this work only the pristine graphene functionality was used, since the sensing channel modelled
here is unfunctionalised graphene. A single layer was generated with the command
\begin{center}
\texttt{python GOPY.py generate\_PG 120 120 graphene\_PG\_12nm.pdb}
\end{center}
where the two numerical arguments are the requested lateral dimensions in \AA{}ngstr\"om. The
resulting sheet was inspected to confirm that it reproduces the expected graphene lattice: it
contains $5700$ carbon atoms spanning $121.6 \times 119.8$~\AA{}, it is strictly planar (all atoms
at $z = 0$, with zero dispersion), and the nearest-neighbour carbon--carbon distance is
$1.418$~\AA{}, the accepted bond length of the graphene honeycomb lattice. Of the $5700$ atoms,
$5488$ are three-coordinated, as expected for the $sp^2$ interior of the lattice, while the
remaining $212$ are the two-- and one--coordinated atoms that necessarily terminate the edges of a
finite, non-periodic sheet. These edge atoms are left unsaturated, as the model is used as a rigid
surface for placement rather than in a reactive or dynamical simulation.

The lateral dimensions were not chosen arbitrarily but from the measured footprints of the probes
themselves (Section~\ref{sec:complexres}), so that every probe of the panel fits within the sheet
with a margin.

\subsection{Assembly of the probe--graphene models}

Each probe is placed above the sheet by a rigid-body translation, computed with a script built on
Biopython \citep{cock2009}. The probe structure (Boltz-2 CIF) and the sheet
(GOPY PDB) are read, and the probe is translated by
\[
\Delta = \Bigl(\bar{x}_{g}-\bar{x}_{p},\;\;
               \bar{y}_{g}-\bar{y}_{p},\;\;
               (\bar{z}_{g}+d) - \min z_{p}\Bigr),
\]
where $\bar{x},\bar{y},\bar{z}$ denote centroid coordinates of the sheet ($g$) and of the probe
($p$), and $d$ is the chosen separation. The first two components centre the probe over the sheet
in the plane; the third places its lowest atom at a height $d$ above the graphene plane.

The separation $d$ is taken from the literature rather than chosen arbitrarily. Van der
Waals-corrected density-functional calculations place physisorbed DNA nucleobases at
$3.16$--$3.22$~\AA{} above the graphene plane, a regime of strong physisorption dominated by van
der Waals interactions \citep{tayo2023}, consistent with the physisorption picture established for
the four bases on graphene and h-BN \citep{lee2013}. Accordingly, $d = 3.2$~\AA{} is used as the
default, so that the assembled model starts at the reported equilibrium contact distance. The
separation is an explicit parameter of the script and can be set to any other value.

The probe's internal conformation and its orientation are left untouched: the operation is a pure
translation, so no coordinate is distorted.

The two structures are then merged into a single model and written as one PDB file. Because the PDB
format identifies each molecular entity by a single-character chain identifier, and none is
reserved for non-biological components such as a graphene layer, an explicit convention was adopted
here: the graphene sheet is assigned chain \texttt{G} and the probe chain \texttt{D}, the initials
of \emph{graphene} and \emph{DNA}. The choice is arbitrary in the sense that any identifiers would
serve, but keeping the two components in separate, consistently named chains is what allows either
of them to be selected unambiguously in downstream tools --- for instance to hold the sheet rigid
during a docking or minimisation run, or to compute probe--surface distances --- and the same
convention is used in every model produced.

Before writing, the script verifies that no probe atom falls outside the sheet footprint in
$x$--$y$ and refuses to produce a model with overhanging atoms, so that an undersized sheet cannot
pass unnoticed. It also reports the shortest probe--sheet interatomic distance, as a check that the
placement introduces no steric clash. The same script builds the entire panel in a single
invocation, writing one model per probe together with a table of their measured footprints,
heights and closest contacts, so that the assembly stage requires no manual intervention.

It should be stressed that this procedure yields a \emph{starting geometry} --- a physically
reasonable initial placement of the two components --- and not a docked, energy-minimised or
dynamically equilibrated structure. It provides the assembled input required by subsequent
molecular docking or force-field refinement, but no interaction energy is computed at this stage.

\subsection{Measurement of the Debye coverage of the models}
\label{sec:debyemethod}

From each model, the part of the probe that lies close enough to the graphene to escape electrostatic
screening is measured. The mean $z$ of the graphene atoms defines the plane of the sheet, and the height
of every probe atom above it is computed. Two quantities are reported: the percentage of probe atoms whose
height does not exceed the Debye length $\lambda_D$, and the number of phosphorus atoms within it. The
second is the more direct measure of what the transistor senses, since the charge of DNA is carried by its
phosphate groups, one negative charge each.

The values of $\lambda_D$ were taken from a study of DNA-hybridisation detection with graphene
transistors that used these same buffers, where they were calculated with the Debye--H\"uckel
approximation \citep{purwidyantri2021}: $0.76$~nm for $1\times$~PBS, $2.41$~nm for
$0.1\times$~PBS and $7.61$~nm for $0.01\times$~PBS.

Three geometries are measured. The first is the rigid placement described above, which keeps the
orientation predicted by Boltz-2. The second reproduces the immobilisation used in the graphene-transistor
studies that define the experimental context of this work, in which the probe carries an amino
modification at its $3'$ end and is bound through \acrfull{pbse}, a linker whose pyrene group adsorbs on
graphene by $\pi$--$\pi$ stacking \citep{campos2019,purwidyantri2021}: the probe is tethered by its $3'$
end. To sample the orientations such a tether allows, each predicted structure is given $20\,000$
orientations, drawn as directions distributed uniformly on the sphere; for a flat sheet, the height of
every atom depends only on which direction of the molecule points away from the surface, so rotations
about that direction need not be sampled. In each orientation the lowest atom is placed at the contact
distance of $3.2$~\AA{} \citep{tayo2023}, and the orientation is retained only if that atom belongs to
the $3'$-terminal nucleotide, that is, if the probe touches the sheet with its $3'$ end. No linker length
is added, so the $3'$ end sits as close to the surface as possible. The median and the maximum over the
retained orientations are reported. The third geometry applies the same procedure to the probe--target
duplex, anchored by the $3'$ end of the probe, and counts the phosphates of the target strand within
$\lambda_D$: the charge that hybridisation brings into the sensing volume. As a check on the predicted
duplex geometry, its rise per base pair is computed from the midpoints of the C1$'$ atoms of the paired
nucleotides and compared with the $0.34$~nm of B-form DNA \citep{watsoncrick1953}.

The probes of each gene are finally compared on two independent axes, the Boltz-2 confidence and the
median number of phosphates within $\lambda_D$ in $1\times$~PBS for the anchored probe. The probes on the
Pareto front of the two --- those for which no other probe of the same gene is at least as good on both
axes and better on one --- form the final selection. Using the front rather than a weighted sum avoids an
arbitrary weighting of two quantities of different nature.

\section{Integration of a reference probe panel}

The pipeline described so far designs probes from scratch. It can also score probes that already
exist, which provides a point of comparison external to the method and a test of whether the
thresholds behave sensibly on sequences they did not select.

An existing experimental probe panel was integrated into the same workflow for comparison. Each reference
probe, supplied as a (\texttt{job\_name}, \texttt{sequence}, \texttt{species}) record, is cleaned (uracil
converted to thymine, non-ACGT characters removed) and scored with exactly the same metrics as the designed
probes, but by the thresholds of its \emph{own} species and type. Conservation is left empty for these
probes, because it is only definable for probes derived from an alignment. The reference probes are stored
alongside the designed ones, with a source label, so that the two sets appear side by side with identical
columns.

\section{Diversity and rarefaction analysis}
\label{sec:diversity}

One parameter has so far been stated without justification: the number of sequences requested per
gene. Choosing it requires knowing how much variation each gene actually contains, which is also
worth knowing in its own right, since it governs how demanding the conservation criterion can be.

The analysis is alignment-free, so that it does not inherit the assumptions of the alignment it is
meant to characterise. Each retrieved sequence is reduced to its vector of $4$-mer counts over the
$256$ possible $4$-mers, normalised to frequencies. Two distances are then computed for every pair
of sequences of a gene: the cosine distance, $1 - \cos\theta$ between the two frequency vectors,
which is sensitive to how often each word occurs; and the Jaccard distance, one minus the ratio of
the number of $4$-mers shared by the two sequences to the number present in either, which ignores
frequency and registers only which words occur. The two therefore measure different things, and
agreement between them is informative. The fraction of sequences that are distinct is reported
alongside, since it detects exact duplicate records.

The sampling depth follows from a rarefaction analysis. For each gene and each $N$ in a fixed
schedule, $N$ sequences are drawn at random without replacement, five times independently; the
mean pairwise cosine distance and the richness, meaning the number of distinct $4$-mers present in
the subsample, are averaged over the five draws. Plotting both against $N$ shows the value beyond
which further sequences add little, which is the value the retrieval step needs.

\section{Implementation and reproducibility}

All intermediate and final results are written as CSV files. Because \acrshort{ncbi} does not always return
an identical set of records, per-gene counts may vary by a few percent between runs; for strict
reproducibility the accession identifiers can be frozen.

The next chapter applies this method to the six-gene panel and reports, stage by stage, what it
produced.
